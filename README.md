**SkyRide** — это трёхмерный аркадный автосимулятор с продвинутым искусственным интеллектом противников, динамической физической моделью и системой хранения данных на базе локальной СУБД SQLite. Разработан на игровом движке **Unity** с использованием языка **C#**.

---

## 🌟 Ключевые особенности

### 🚗 1. Физическая модель и управление
* **WheelCollider & Rigidbody:** Реалистичное распределение массы с заниженным центром тяжести для предотвращения переворотов на крутых виражах.
* **Ассистенты помощи водителю (Safety Systems):**
  * **ABS** (Anti-lock Braking System) — предотвращает блокировку колес при резком торможении.
  * **TCS** (Traction Control System) — контролирует пробуксовку ведущих колес при избыточном газе.
  * **ESC** (Electronic Stability Control) — выравнивает угловое вращение автомобиля при заносах.
* **Downforce:** Динамическая прижимная сила, возрастающая пропорционально скорости автомобиля.
* **Unity Input System:** Кроссплатформенная поддержка клавиатуры, мышей и геймпадов.

### 🤖 2. Умные ИИ-соперники (AI Drivers)
* **Траектории на сплайнах Кэтмулла-Рома:** Боты плавно следуют по трассе, рассчитывая мягкие дуги поворотов вместо движения по резким ломаным линиям.
* **Look-Ahead Deceleration:** ИИ «смотрит» на несколько нод вперед по сплайну, анализирует кривизну поворота и заранее притормаживает до безопасной скорости.
* **Система Anti-Stuck:** Автоматический детектор застревания — если бот уперся в ограждение, он самостоятельно сдаст назад, совершит маневр обхода и вернется на траекторию.

### 📊 3. Локальная СУБД SQLite (Data-Driven подход)
* **Профили соперников:** Характеристики ботов (максимальная скорость, уровень сцепления с дорогой) загружаются динамически из базы данных `race_database.db`.
* **Таблица рекордов (Leaderboard):** Лучшие круги игрока автоматически сохраняются в базу данных по окончании заезда.
* **Кроссплатформенная защита:** Инициализация базы данных адаптирована под любые региональные настройки Windows (исправлена проблема разделителей дробной части в SQLite).

### 🏁 4. Логика гонки и Эстетичный UI
* **Sequential Checkpoints:** Защита от срезания кругов. Каждый чекпоинт должен быть взят строго по порядку номеров.
* **Приборная панель (HUD):**
  * Динамический тахометр с симуляцией инерции стрелки и эффектом вибрации при отсечке.
  * Цифровой спидометр и индикатор текущей передачи.
* **GPS Навигатор:** Стрелка-указатель на Canvas, рассчитывающая точный угол до следующей точки по кратчайшей траектории относительно взгляда игрока (камеры) или капота автомобиля.

## 🛠 Математический аппарат проекта

Проект демонстрирует применение классической геометрии и тригонометрии в геймдеве:

### А. Навигация стрелки (2D Compass)
Для определения угла поворота стрелки $\theta$ на 2D-интерфейсе, 3D-вектор направления на цель $\vec{d}$ проецируется на локальные оси автомобиля («вперед» $\vec{f}$ и «вправо» $\vec{r}$) с использованием скалярного произведения векторов (`Vector3.Dot`), после чего вычисляется арктангенс:

$$\theta = \operatorname{atan2}(\vec{d} \cdot \vec{r}, \vec{d} \cdot \vec{f}) \cdot \frac{180}{\pi}$$

Сглаживание переходов выполняется по формуле сферической интерполяции кватернионов:
$$Q_{\text{new}} = \operatorname{Slerp}(Q_{\text{current}}, Q_{\text{target}}, \text{Speed} \cdot \Delta t)$$

### Б. Сплайны Кэтмулла-Рома (Сглаживание путей)
Для интерполяции координат между четырьмя контрольными точками $P_0, P_1, P_2, P_3$ с шагом времени $t \in [0, 1]$ используется кубическая функция:

$$P(t) = 0.5 \cdot \left( (2 P_1) + (-P_0 + P_2) \cdot t + (2P_0 - 5P_1 + 4P_2 - P_3) \cdot t^2 + (-P_0 + 3P_1 - 3P_2 + P_3) \cdot t^3 \right)$$

## 📁 Структура ключевых скриптов

```yaml
Assets/
 ├── Ai Logic/
 │    ├── AICarDriver.cs         # Поведение ботов, Look-Ahead и Anti-Stuck система
 │    ├── CatmullRomSpline.cs    # Математические функции интерполяции путей
 │    └── WaypoinContainer.cs    # Контейнер для хранения нод траектории
 ├── UI/
 │    └── Scripts/
 │         ├── WaypointArrow.cs  # Логика стрелки GPS-навигатора
 │         ├── TachometerUI.cs   # Физическое поведение стрелки тахометра
 │         └── RaceManager.cs    # Чекпоинты, круги, таймеры и динамическая пауза
 └── Plugins/                    # SQLite библиотеки для кроссплатформенного подключения БД
```

## 🚀 Быстрый старт

### Требования
* **Unity 2022.3 LTS** или новее.
* Импортированный пакет **TextMesh Pro**.
* Импортированный пакет **Input System** (через Unity Package Manager).

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/SkyRide.git
   ```
2. Откройте папку проекта в **Unity Hub**.
3. Запустите сцену `Assets/Scenes/Scene_Race_Track1.unity`.
4. Нажмите кнопку **Play** для начала игры.

## 🎮 Управление (По умолчанию)
